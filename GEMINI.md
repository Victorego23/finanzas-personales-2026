# Proyecto: Control Financiero Personal 2026

Herramienta web minimalista, privada y moderna para el control de finanzas personales enfocado en el año 2026.

## Arquitectura del Proyecto

- `index.html`: Estructura HTML5 semántica.
- `styles.css`: Sistema de diseño Fintech Dark Mode con CSS Variables, Glassmorphism y utilidades responsivas.
- `app.js`: Controlador de estado, persistencia en `localStorage`, cálculo en tiempo real y módulo de importación/exportación JSON.
- `.agents/rules/senior-engineer.md`: Reglas del repositorio para desarrollo asistido con perfil Senior.

## Estándares de Código

- No usar dependencias externas pesadas.
- Mantener la privacidad de los datos al 100% (cero llamadas a API externas sin autorización).
- Tipografía moderna (Inter / System UI).
